# 乎零 R01 官网原型

中文、响应式、无构建依赖的产品介绍网站。下载后打开 index.html，或运行 `python3 -m http.server 8080` 后访问 http://localhost:8080。

## 本轮内容

首页主标题采用“不止健康，下一代智能戒指”。五段滚动叙事围绕“掌控想法、掌控身体”展开，Canvas 戒指随滚动转动、推近与换位。记录按钮演示原始语音到灵感整理的变化，末尾提供常见问题。支持手机布局、键盘操作和减少动态效果设置。

## 内容依据与评审边界

2026-11-05，根据乎零 R01 导演台预演交接、品牌设计 Brief 和 VI v1.1 制作。用户本轮明确确认 R01 已通过 IPX8 测试，页面据此呈现。品牌资产使用现有正式字标。

戒指外观由 Canvas 实时绘制三维网格并标明示意，记录交互为概念演示。模型为按产品资料制作的外观研究，待替换实际产品模型。4.6 g 来自当前预演资料，实际尺码适用范围待补充。状态理解、双击记录与 App 整理按现有品牌和产品资料展示，首发能力待与交付版本逐项核对。续航、售价、兼容性和购买渠道尚待补充。

这是供页面内容和视觉评审的原型。未附内部资料、测试报告、私人路径或任何账号信息。
