# 乎零 R01 官网原型

中文、响应式、无构建依赖的产品介绍网站。下载后打开 index.html，或运行 `python3 -m http.server 8080` 后访问 http://localhost:8080。

## 本轮内容

首页主标题采用“不止健康，下一代智能戒指”。五段滚动叙事围绕“掌控想法、掌控身体”展开，Canvas 戒指随滚动转动、推近与换位。记录按钮演示原始语音到灵感整理的变化，末尾提供常见问题。支持手机布局、键盘操作和减少动态效果设置。

## 内容依据与评审边界

2026-11-05，根据乎零 R01 导演台预演交接、品牌设计 Brief 和 VI v1.1 制作。用户本轮明确确认 R01 已通过 IPX8 测试，页面据此呈现。品牌资产使用现有正式字标。

戒指外观由 Canvas 实时绘制三维网格并标明示意，记录交互为概念演示。模型为按产品资料制作的外观研究，待替换实际产品模型。4.6 g 来自当前预演资料，实际尺码适用范围待补充。状态理解、双击记录与 App 整理按现有品牌和产品资料展示，首发能力待与交付版本逐项核对。续航、售价、兼容性和购买渠道尚待补充。

这是供页面内容和视觉评审的原型。未附内部资料、测试报告、私人路径或任何账号信息。

## 2026-11-05 实拍参考银色模型首版

本轮根据用户提供的五张实拍重建三维戒指，替换原 Canvas 多边形示意。使用本地 WebGL 网格与材质渲染，单一上下文、静态缓冲、滚动时按需绘制，无额外运行依赖。双层外壳、装配缝、抛光内圈边缘及向内折角分开建模。按键略凸，麦克风有凹陷网层，小指示灯在记录章节亮白光。两大两小内侧窗口按用户确认制作。

基础比例沿用宽 7.5 mm、径向厚约 2.5 mm、内径约 17.3 mm 的已有资料。局部尺寸按照片估计，按键直径约 3.6 mm、麦克风约 1.55 mm、指示灯约 0.5 mm，按键凸起约 0.25 mm。孔位夹角及窗口结构属于首版估算，未取得工程图或 CAD，不能视为尺寸验收。材质采用细磨砂银色外圈、反光更强的内圈和窄亮边，本轮统一银色，颜色选择保留名称但暂不改变模型颜色。

`ring-renderer.js` 为独立渲染模块。`model-review.html` 提供旋转、缩放、部件视角和灯光开关。官网六段轨迹已经接入，身体章节用内圈视角、记录章节用外侧控制部件视角。无 WebGL 时使用本模型生成的静态回退 PNG。

已用 Playwright 专用隔离会话检查 1440、1024、768、390、320px 下的六段滚动章节，未见横向溢出或脚本异常。检查页视角切换、键盘旋转、缩放、灯光开关及无 WebGL 回退通过。截图位于本机临时 QA 目录，未上传实拍原件。当前产出为待用户审阅首版，后续优先校准孔位、内圈折角和传感器比例。
